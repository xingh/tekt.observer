## Sequencing

The three active plans form a dependency chain:

1. **RM-016 — crawl4ai integration** (near-term, no deps)
   CSS-selector-based `crawl4ai_browser` discovery mode + cookie-consent consolidation. This is the foundation.

2. **RM-018 — browser-use integration** (medium-term, depends on RM-016 Phase 1)
   browser-use acts as a reconnaissance driver: it discovers page structure and outputs CSS selectors that feed into the crawl4ai config created by RM-016. Phase 2 adds an interactive `browser_use` discovery mode. Phase 3 packages tekt.observer as browser-use custom tools.

3. **RM-017 — Claude skills packaging** (medium-term, independent but benefits from RM-018)
   Skills-only export first, then MCP server. The MCP server can expose the same tools that Phase 3 of RM-018 packages for browser-use, creating a unified tool surface.

RM-016 and RM-017 Phase 1 can proceed in parallel. RM-018 Phase 1 starts after RM-016 Phase 1 lands. RM-017 Phase 2 (MCP server) and RM-018 Phase 3 (browser-use tools) share significant overlap and should be coordinated.
